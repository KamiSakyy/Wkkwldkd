# Lumi ✨ — нативное Android-приложение (Java)

**Люми** — ИИ-подруга (18 лет) в твоём кармане: чат, арты, персонажи аниме и уведомления о новых сериях.
Это НЕ сайт и НЕ WebView-обёртка — полноценное нативное приложение на **Java** (Android SDK, без сторонних библиотек для сети/картинок).

## Скачать APK
- Файл в репозитории: `apk/Lumi-Chat-v2.0-debug.apk`
- Либо собери сам: push в репозиторий → GitHub Actions «Build Lumi APK» → артефакт `Lumi-APK`.

## Что внутри

| Вкладка | Умеет |
|---|---|
| 💬 **Чат** | Люми-стриминг ответов (llm7.io `GLM-5.3-Flash`, бесплатные модели, фолбэки), память («меня зовут…», «запомни…»), голосовой ввод 🎙, озвучка TTS 🔊, арты и персонажи прямо в чате |
| 🎨 **Арты** | Живые источники: nekos.best, waifu.im, Kitsu, AniList (и ИИ-генерация Pollinations, если добавить свой токен в настройках). Категории, поиск, избранное ⭐, скачивание, **установка обоев** |
| 👤 **Персонажи** | Расширенный поиск **имя + аниме** (AniList GraphQL, резерв Kitsu): фото, биография, избранное, шеринг |
| 📺 **Аниме** | Расписание эфиров на 7 дней, поиск, **подписка на серии** → push-уведомление, когда выходит новая серия (AniList, работает в фоне, переживает перезагрузку) |

Плюс: шеринг артов в любые соцсети/мессенджеры через системное меню «Поделиться» (Telegram, Twitter/X, Facebook, WhatsApp — без ключей), тёмная аниме-тема, иконка запуска.

## Почему это работает (а сайт сломался)
- Сайт искал картинки скрапингом DuckDuckGo → его забанили, ссылки битые.
- Pollinations (генерация) стал платным (402).
- В приложении только **проверенные живые источники** с многоуровневыми фолбэками: если один не отвечает — автоматом берётся следующий.

## Сборка из командной строки
```bash
gradle assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
```
Требуется JDK 17 и Android SDK (платформа 34). В CI всё уже настроено.

## Настройки (необязательно)
- Модель llm7 (по умолчанию `GLM-5.3-Flash` — бесплатная)
- Токен llm7 — для turbo-моделей
- Токен Pollinations — включает ИИ-генерацию артов «с нуля» («нарисуй…»)
- TTS-озвучка ответов

## Технологии
Java 17 · Android SDK 34 (minSdk 26) · HttpURLConnection + org.json (без Retrofit/OkHttp) ·
SQLite · AlarmManager · собственный ImageLoader (LruCache + диск) · Material 3.

GitHub Actions: `build-apk.yml` (сборка APK), `ask-lumi.yml` (опрос пожеланий Люми через llm7 → `lumi/wishes.md`).
